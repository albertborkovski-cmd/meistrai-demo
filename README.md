# Meistrai – GitHub demonstracija

Vieša specialistų paieškos ir darbų valdymo demonstracija. Prisijungimo nereikia.

Visos užklausos, pasiūlymai, darbų aktai, žinutės ir pridėti failai saugomi tik naudotojo naršyklėje (IndexedDB). Kitas įrenginys jų nemato. Išvalius šios svetainės duomenis naršyklėje, bandymai pašalinami. Naudokite tik pavyzdinius duomenis. Mokėjimai imituojami, tikros paslaugos neužsakomos.

## Išbandyti

1. Kliento režime sukurkite darbų užklausą.
2. Meniu perjunkite į specialistą ir pateikite pasiūlymą.
3. Grįžkite į kliento režimą ir priimkite pasiūlymą.
4. Specialisto režime pradėkite etapą ir pateikite darbų aktą.
5. Kliento režime priimkite aktą arba grąžinkite taisyti.
6. Prieš galutinį mokėjimą išbandykite papildomų darbų pasiūlymą.
7. Priimkite darbus ir imituokite mokėjimą.

Tai sukompiliuoti demonstracinės svetainės failai. Pagrindinė projekto saugykla yra privati. Nuotraukų autoriai nurodyti programos pagalbos lange.
